Quick Pay

Simple USDC payments built for Arc.

Quick Pay is a lightweight payment application designed for simple USDC payments on Arc Testnet.

Features

- Connect EVM wallet
- View USDC balance
- Send USDC
- Add an optional payment note
- View transaction status
- View transaction hash
- Mobile-friendly interface

How It Works

1. Connect your wallet
2. Check your USDC balance
3. Enter the recipient address
4. Enter the USDC amount
5. Add an optional payment note
6. Send the payment
7. View the confirmed transaction
